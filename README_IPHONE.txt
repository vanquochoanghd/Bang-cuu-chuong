SIÊU NHÂN BẢNG CỬU CHƯƠNG — WEB APP CÓ THỂ CÀI MÀN HÌNH CHÍNH

Đây là PWA (web app), không phải IPA/App Store app.

Cài đặt:
1. Đưa toàn bộ các file trong thư mục này lên một host HTTPS hỗ trợ website tĩnh (ví dụ GitHub Pages hoặc Netlify).
2. Mở URL HTTPS đó trong Safari trên iPhone.
3. Nhấn Chia sẻ → Thêm vào Màn hình chính → Thêm.
4. Mở biểu tượng mới tạo. Sau khi tải game lần đầu và service worker lưu cache thành công, game có thể hoạt động offline.

Không thể cài PWA bằng cách chỉ mở file HTML cục bộ trong ứng dụng Tệp. Cần xuất bản lên HTTPS một lần. Tôi chưa đăng tải thư mục này lên Internet và chưa có URL công khai.
