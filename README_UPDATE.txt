CẬP NHẬT GAME SIÊU NHÂN BẢNG CỬU CHƯƠNG — V2

Tính năng mới:
- Bảng nhân, bảng chia, ngẫu nhiên (nhân và chia ngẫu nhiên), hoặc kết hợp nhân + chia.
- Chọn nhiều bảng để luyện; chọn 10 hoặc 15 câu mỗi chặng.
- Phần thưởng sau mỗi chặng, điểm/sao/kỷ lục và bộ sưu tập 8 tranh cổ vũ.
- PWA có service worker để hỗ trợ chơi offline sau khi tải cache.

CÁCH CẬP NHẬT WEBSITE GITHUB PAGES:
1. Giải nén ZIP này.
2. Mở repository GitHub Bang-cuu-chuong.
3. Nhấn Add file -> Upload files.
4. Tải lên index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png và toàn bộ thư mục images (8 file jpg).
5. Chọn ghi đè các file trùng tên, rồi Commit changes.
6. Chờ GitHub Pages triển khai xong, mở lại link game.
7. Nếu iPhone vẫn hiện bản cũ, đóng game, mở link bằng Safari rồi làm mới trang; có thể cần xóa biểu tượng cũ và thêm lại sau khi cập nhật.

Lưu ý: GitHub Pages công khai cho mọi người có link. Đây là game HTML5/PWA, không phải Flash .swf hoặc IPA.
